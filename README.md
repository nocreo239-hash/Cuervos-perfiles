# cuervos-perfiles

Imágenes **aprobadas** del sistema de perfiles de fotos para mundos de VRChat.
Se publican con GitHub Pages (`*.github.io`), un dominio de confianza para VRChat.

No se guardan aquí códigos de perfil, nombres de clientes ni datos de instancias.

## Estructura

```
casa/                 mundo "la casa (BETA)"
  layout.json         espacios del mapa: id, proporción, hoja y rectángulo dentro de la hoja
  p/NNNN_H.jpg        hoja H (0 o 1) del perfil NNNN, 2048x2048
```

`0000` y `0001` son perfiles de prueba.
